# Kinetic Model Energy Choice — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the engine choose a sweep's collision energy by the progress report's Kinetic Model — a Gompertz curve fitted to the precursor share of a few pre-scans, fed into the fragment-pool recursion with an authored k₂, argmax = the Modeled maximum — at MS2 and MS3, validated against the 108-sweep study, with the live fit logged.

**Architecture:** A new pure-function helper `KineticModel.{h,cpp}` (share, bounded Levenberg-Marquardt Gompertz fit, pool recursion, argmax) sits beside the other FLASHIda runtime helpers and is tested alone against tables generated by the study's own (vendored) pipeline. `Exploration` gains a fourth metric `kinetic_model` whose group completion fits instead of picking a winner and always emits a follow-up at the modeled energy. The CE-0 baseline and the remaining ratio go away under every metric; the precursor share replaces them on every MSn row of `scan_results.tsv`.

**Tech Stack:** C++20 (Eigen `unsupported/NonLinearOptimization`, already used by `GaussFitter`/`GumbelMaxLikelihoodFitter`), C# 7.3 (.NET Framework 4.8), Python 3 via `uv` for the table generator and fixture cuts, the two Docker containers (`ci cpp`, `ci cs`, `ci golden-diff`).

**Spec:** `docs/adr/0047-a-sweep-decides-by-the-modeled-maximum-not-by-a-measured-point.md` and `docs/adr/0048-precursor-share-replaces-the-remaining-ratio-and-a-sweep-has-no-baseline.md` (both Proposed, written 2026-10-11), with the glossary entries added to `CONTEXT.md` the same day. The grilling record is in the session memory `project-kinetic-model-energy-choice.md`.

## TL;DR in plain language

Today a sweep acquires a CE-0 reference scan plus a grid of energies, scores every pre-scan as it returns, and acquires the production scan at the best-scoring grid point. After this plan, a sweep under the new metric acquires only its grid points (no reference scan anywhere), reads from each the fraction of the scan's signal that is still precursor, fits the study's Gompertz curve to those fractions, runs the study's fragment-pool recursion with the authored k₂, and acquires the production scan at the integer energy where the pool peaks — an energy no pre-scan need have run at. Every number of the fit is written to `scan_results.tsv` on the row that completes the group, and the share is written on every MS2/MS3 row so a dense Orbitrap MS3 sweep becomes a dataset for fitting an MS3 k₂ offline.

```
BEFORE (every metric)                         AFTER
CE0 ──┐                                      ce_min ──┐  share P₁
20  ──┤ ratio = window/CE0-window            ...     ──┤  share P_i   = window Σ / whole-scan Σ
25  ──┤ score = 1-|ratio-target|              ce_max ──┘  share P_n   (top edge ALWAYS acquired)
30  ──┤                                                      │
35  ──┤ winner = argmax score ──► R @ 35                     ▼ Gompertz fit (P₀, CE_max s, w)  ≥3 points
40  ──┘                                                      ▼ s(CE) = −dP/dCE on 1..ce_max
                                                             ▼ B(k) = e^{−k₂}B(k−1) + s_k(1−e^{−k₂})/k₂
                                                             ▼ CE* = argmax B   (may be < ce_min)
                                                             R @ CE*   — or [EXPL-ABORT] reason=no-fit
```

## Context

The progress report of 2026-09-30 (section "Precursor Tuned Fragmentation") shows on 108 HCD sweeps of 11 proteins that six ion-trap pre-scans plus the Kinetic Model reach a mean regret of 0.149 against 0.357 for the best fixed energy, and names "validate for ion-trap scans, then MS3" as the work in progress. A production MS3 scan costs ~5 s and a 14-point grid per target 69 s; the 2026-07-08 cytochrome c run spent 19.5 min of MS3 on 17 targets of one MS2. Nothing of the model exists in the engine (no curve fit, no derivative, no k₂, no whole-spectrum sum). The owner's decisions were taken in a 23-question grilling on 2026-10-11 and are recorded in the two ADRs; this plan implements them and nothing else.

## Review Focus

Inputs the ADRs imply but no task's tests exercise, most likely to bite first. Each gets a test in the task named.

1. **A sweep whose shares never fall** (precursor too stable for the grid, e.g. a trap pre-scan on a 30 kDa protein at HCD 10–30): the Gompertz fit converges to a huge c or a wall; CE* lands at `ce_max` with `at_upper_edge`. Expected: a follow-up at `ce_max` with the flag logged, not an abort. → Task 10 `kinetic_model_flat_shares_choose_the_upper_edge_and_flag_it`.
2. **A share above 1 or a zero-total scan** (empty trap read, or a notch misreport): share must be `-1` (not 0) when the total is 0, must be excluded from the fit as non-finite, and must not count toward the 3-point minimum. → Task 2 `precursorShare_returns_minus_one_on_an_empty_scan`, Task 10 `kinetic_model_excludes_non_finite_shares`.
3. **MS3 share on a two-stage command reads stage 1's window, never stage 0's** — reading stage 0 would measure the intact precursor, flat across stage-1 energies. → Task 10 `kinetic_model_ms3_reads_the_stage1_window`.
4. **`energy_source` and the fit columns appear on exactly one row per group** (the completing one) and are sentinels everywhere else, including the follow-up 'R' row. → Task 11 `results_kinetic_columns_only_on_the_completing_row`.
5. **Config with `kinetic_model` object but `metric: "remaining_precursor"`** must throw (an authored k₂ nobody reads is the stomped-key shape). → Task 8 `kinetic_model_object_without_the_metric_throws`.

```cpp
    // Grid points from min by step, then the top edge if the range does not divide (ADR-0047 decision 8).
    // Index arithmetic, not accumulation: `ce += step` drifts and the old `<= max + 1e-9` dropped the edge.
    auto grid = [](double lo, double hi, double step) {
      std::vector<double> g;
      const int n = static_cast<int>(std::floor((hi - lo) / step + 1e-9)) + 1;
      for (int i = 0; i < n; ++i) g.push_back(lo + i * step);
      if (g.empty() || g.back() < hi - 1e-9) g.push_back(hi);
      return g;
    };
    std::vector<double> ces = grid(cfg.ce_min, cfg.ce_max, cfg.ce_step);
    std::vector<double> rts;
    if (cfg.rt_max > cfg.rt_min) rts = grid(cfg.rt_min, cfg.rt_max, cfg.rt_step);
```

```cpp
namespace OpenMS::KineticModel
{
  constexpr double kWidthMin      = 0.25;  // NCE, the study's grid floor
  constexpr double kWidthMax      = 25.0;  // NCE, the study's grid ceiling
  constexpr double kPlateauFactor = 1.1;   // P0 <= 1.1 x highest acquired share (the "bounded" arm)
  constexpr int    kMinPoints     = 3;     // fewer finite shares -> no fit
  constexpr double kSeedWidth     = 4.2;   // median width of the 108 study sweeps; seed when no 0.85 crossing

  struct SharePoint { double ce = 0.0; double share = -1.0; };   // share < 0 or non-finite = excluded

  struct GompertzFit
  {
    bool   ok = false;
    double p0 = -1.0, ce_max_s = -1.0, width = -1.0, rss = -1.0;
    int    n_points = 0;
    double share(double ce) const;   // P(ce) = p0 * exp(-exp((ce - ce_max_s)/width)); 0 when !ok
    double rate(double ce)  const;   // s(ce) = -dP/dce >= 0; 0 when !ok
  };

  struct ModeledMaximum
  {
    int    ce = 0;        // 0 = none (no fit)
    double b  = -1.0;     // pool value at ce
    bool   at_lower_edge = false, at_upper_edge = false;   // ce == 1, ce == ce_max
  };

  /// Sum of ints with mz in [mz_lo, mz_hi] over the sum of all ints. -1.0 when n <= 0 or the total is <= 0.
  OPENMS_DLLAPI double precursorShare(const double* mzs, const double* ints, int n, double mz_lo, double mz_hi);
  /// Bounded LM fit (ADR-0047 decision 3). Points with share < 0 or non-finite are dropped first.
  OPENMS_DLLAPI GompertzFit fitGompertz(const std::vector<SharePoint>& points);
  /// B(k) = e^{-k2} B(k-1) + s_k (1 - e^{-k2}) / k2, k = 1..rate.size(), B(0) = 0.  (pipeline.direct)
  OPENMS_DLLAPI std::vector<double> fragmentPool(const std::vector<double>& rate, double k2);
  /// rate on 1..ce_max from the fit, the pool, the integer argmax (lowest CE on a tie).
  OPENMS_DLLAPI ModeledMaximum modeledMaximum(const GompertzFit& fit, double k2, int ce_max);
}
```

```cpp
#include <unsupported/Eigen/NonLinearOptimization>
#include <unsupported/Eigen/NumericalDiff>
#include <algorithm>
#include <cmath>
#include <limits>

    inline double sigmoid(double t) { return 1.0 / (1.0 + std::exp(-t)); }
    inline double logit(double p) { p = std::min(std::max(p, 1e-6), 1.0 - 1e-6); return std::log(p / (1.0 - p)); }
    inline double clampU(double u) { return std::min(std::max(u, -60.0), 60.0); }   // curve_families.U

    /// Coordinates LM sees: x(0) -> P0 through cap*sigmoid, x(1) = c free, x(2) -> w through the log box.
    struct Decoded { double p0, c, w; };
    inline Decoded decode(const Eigen::VectorXd& x, double cap)
    {
      return {cap * sigmoid(x(0)), x(1), kWidthMin * std::pow(kWidthMax / kWidthMin, sigmoid(x(2)))};
    }
    inline Eigen::VectorXd encode(double p0, double c, double w, double cap)
    {
      Eigen::VectorXd x(3);
      x(0) = logit(p0 / cap);
      x(1) = c;
      x(2) = logit(std::log(w / kWidthMin) / std::log(kWidthMax / kWidthMin));
      return x;
    }

    // Generic functor shape Eigen's NumericalDiff/LevenbergMarquardt expect (same idiom as
    // GumbelMaxLikelihoodFitter.cpp).
    template<typename _Scalar, int NX = Eigen::Dynamic, int NY = Eigen::Dynamic>
    struct Functor
    {
      typedef _Scalar Scalar;
      enum { InputsAtCompileTime = NX, ValuesAtCompileTime = NY };
      typedef Eigen::Matrix<Scalar, InputsAtCompileTime, 1> InputType;
      typedef Eigen::Matrix<Scalar, ValuesAtCompileTime, 1> ValueType;
      typedef Eigen::Matrix<Scalar, ValuesAtCompileTime, InputsAtCompileTime> JacobianType;
      int m_inputs, m_values;
      Functor(int inputs, int values) : m_inputs(inputs), m_values(values) {}
      int inputs() const { return m_inputs; }
      int values() const { return m_values; }
    };

    struct GompertzFunctor : Functor<double>
    {
      const std::vector<SharePoint>& pts; double cap;
      GompertzFunctor(const std::vector<SharePoint>& p, double c) : Functor<double>(3, (int)p.size()), pts(p), cap(c) {}
      int operator()(const Eigen::VectorXd& x, Eigen::VectorXd& f) const
      {
        const Decoded d = decode(x, cap);
        for (int i = 0; i < values(); ++i)
          f(i) = pts[i].share - d.p0 * std::exp(-std::exp(clampU((pts[i].ce - d.c) / d.w)));
        return 0;
      }
    };

    /// Landmark seed (the report's "read without a fit"): P0 = highest share; c = first crossing of P0/e after
    /// the maximum, interpolated; w from the 0.85*P0 crossing: w = (ce_85 - c) / ln(-ln 0.85). Fallbacks:
    /// c = last ce, w = kSeedWidth.
    Decoded landmarkSeed(const std::vector<SharePoint>& pts)
    {
      int imax = 0;
      for (int i = 1; i < (int)pts.size(); ++i) if (pts[i].share > pts[imax].share) imax = i;
      const double p0 = pts[imax].share;
      auto crossing = [&](double level, bool& found) {
        for (int i = imax; i + 1 < (int)pts.size(); ++i)
          if (pts[i].share >= level && pts[i + 1].share < level)
          {
            found = true;
            const double t = (pts[i].share - level) / (pts[i].share - pts[i + 1].share);
            return pts[i].ce + t * (pts[i + 1].ce - pts[i].ce);
          }
        found = false; return pts.back().ce;
      };
      bool fc = false, f85 = false;
      const double c  = crossing(p0 / std::exp(1.0), fc);
      const double c85 = crossing(0.85 * p0, f85);
      double w = kSeedWidth;
      if (fc && f85) w = (c85 - c) / std::log(-std::log(0.85));   // ln(-ln 0.85) = -1.817 -> w > 0 since c85 < c
      w = std::min(std::max(w, kWidthMin * 1.2), kWidthMax / 1.2);
      return {std::max(p0, 1e-3), c, w};
    }
  }

  double GompertzFit::share(double ce) const
  {
    if (!ok) return 0.0;
    return p0 * std::exp(-std::exp(clampU((ce - ce_max_s) / width)));
  }
  double GompertzFit::rate(double ce) const
  {
    if (!ok) return 0.0;
    const double e = std::exp(clampU((ce - ce_max_s) / width));
    return std::max(0.0, p0 * e * std::exp(-e) / width);     // curve_families "Gompertz" -dg/dx
  }

  double precursorShare(const double* mzs, const double* ints, int n, double mz_lo, double mz_hi)
  {
    if (mzs == nullptr || ints == nullptr || n <= 0) return -1.0;
    double total = 0.0, window = 0.0;
    for (int i = 0; i < n; ++i)
    {
      total += ints[i];
      if (mzs[i] >= mz_lo && mzs[i] <= mz_hi) window += ints[i];
    }
    return total > 0.0 ? window / total : -1.0;
  }

  GompertzFit fitGompertz(const std::vector<SharePoint>& points)
  {
    GompertzFit out;
    std::vector<SharePoint> pts;
    for (const auto& p : points) if (std::isfinite(p.share) && p.share >= 0.0 && std::isfinite(p.ce)) pts.push_back(p);
    std::sort(pts.begin(), pts.end(), [](const SharePoint& a, const SharePoint& b) { return a.ce < b.ce; });
    out.n_points = (int)pts.size();
    if (out.n_points < kMinPoints) return out;
    double hi = 0.0; for (const auto& p : pts) hi = std::max(hi, p.share);
    if (hi <= 0.0) return out;
    const double cap = kPlateauFactor * hi;
    const Decoded seed = landmarkSeed(pts);
    Eigen::VectorXd x = encode(std::min(seed.p0, 0.99 * cap), seed.c, seed.w, cap);
    GompertzFunctor functor(pts, cap);
    Eigen::NumericalDiff<GompertzFunctor> nd(functor);
    Eigen::LevenbergMarquardt<Eigen::NumericalDiff<GompertzFunctor>, double> lm(nd);
    lm.parameters.maxfev = 2000;
    const Eigen::LevenbergMarquardtSpace::Status status = lm.minimize(x);
    if (status == Eigen::LevenbergMarquardtSpace::ImproperInputParameters
        || status == Eigen::LevenbergMarquardtSpace::TooManyFunctionEvaluation) return out;   // GaussFitter's rule
    const Decoded d = decode(x, cap);
    Eigen::VectorXd f(pts.size()); functor(x, f);
    const double rss = f.squaredNorm();
    if (!std::isfinite(d.p0) || !std::isfinite(d.c) || !std::isfinite(d.w) || !std::isfinite(rss)) return out;
    out.ok = true; out.p0 = d.p0; out.ce_max_s = d.c; out.width = d.w; out.rss = rss;
    return out;
  }

  std::vector<double> fragmentPool(const std::vector<double>& rate, double k2)
  {
    std::vector<double> B(rate.size(), 0.0);
    const double a = std::exp(-k2), g = -std::expm1(-k2) / k2;     // pipeline.direct, verbatim
    double b = 0.0;
    for (size_t k = 0; k < rate.size(); ++k) { b = a * b + rate[k] * g; B[k] = b; }
    return B;
  }

  ModeledMaximum modeledMaximum(const GompertzFit& fit, double k2, int ce_max)
  {
    ModeledMaximum m;
    if (!fit.ok || ce_max < 1 || !(k2 > 0.0)) return m;
    std::vector<double> s(ce_max);
    for (int ce = 1; ce <= ce_max; ++ce) s[ce - 1] = fit.rate(ce);
    const auto B = fragmentPool(s, k2);
    int best = 0;
    for (int k = 1; k < ce_max; ++k) if (B[k] > B[best]) best = k;    // strict: lowest CE on a tie
    m.ce = best + 1; m.b = B[best];
    m.at_lower_edge = (m.ce == 1); m.at_upper_edge = (m.ce == ce_max);
    return m;
  }
}
```

```cpp
  std::vector<Row> readKineticTsv(const std::string& path, std::string& provenance)
```
